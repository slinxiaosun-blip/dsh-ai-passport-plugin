5 · LVGL 落地映射

改版集中在 app_ui_theme.h（令牌与风格助手）+ 两个界面文件的样式调用，布局栅格骨架基本不动。

设计元素LVGL 实现现有代码位置
圆角卡片 R14/R16 lv_obj_set_style_radius(obj, 14/16, 0) + 淡描边 border_width 1 / border_color UI_STROKE ui_theme_box() 改造：加 radius 参数，或新增 ui_theme_card(obj, bg, r)
药丸（徽章/按钮） lv_obj_set_style_radius(obj, LV_RADIUS_CIRCLE, 0)（高 44/18 自动成胶囊） 新增 ui_theme_pill()；审批页两个选项按钮 app_screens.c
透明度色底（徽章 12% 底、选中行 10% 底） LVGL8 用 lv_color_mix(fg, bg, opa) 预混出实色常量，避免半透明叠加开销 调色板区新增 UI_ACCENT_BG / UI_WARN_BG / UI_ERR_BG / UI_INFO_BG 四个预混色
选中态三重冗余（色底 + 2px 描边 + 圆点） border_width 2 + UI_ROW_SEL 换预混绿底 + 5px 圆点小对象 UI_ROW_SEL 重新定义；选项行渲染处 app_screens.c
电量图标 / 信号格 纯色小对象拼装（现状已是色块画法），只加 radius app_ui.c 状态条区
Toast 圆角浮层 + 遮罩 Toast 容器 R16；遮罩用半透明黑全屏对象（LVGL opa 支持，无性能问题） s_toast 样式区 app_ui.c
落地注意（都是这个仓库踩过的坑，别再踩）：
① 阴影不用。手机质感的核心是圆角 + 分层表面色，不是投影；LVGL box shadow 全屏重绘开销大，三层表面色 + 1px 淡描边已足够精致。
② 纵向预算必须同步改。tools/verify-layout.py 与 tests/test_ui_pixel_math.c 校验的是旧硬边版面的坐标预算（状态条 28 / 底栏 56 等），新版式（状态条 22 / 状态卡 30..212 / 底栏卡 76）要一起更新，否则静态校验直接红。
③ 字体管线不动。文案若有新增（如「正在聆听…」「自定义答案…」），跑 tools/make-fonts.py 重新提取字形子集——缺字就是方框，这是两次真机返工的教训。
④ 半透明禁止直接用 opa 属性叠加在滚动内容上（LVGL 会退化成离屏合成），一律预混实色。
⑤ 改版验收用截图链路。app_screenshot.c 已具备截图能力，逐页截图与设计稿比对，别盲改。
